# VerseForMe — Bible Verses for Modern Life

**Live → [versefor.me](https://versefor.me)**

Static site offering Bible verses and prayers for 60+ everyday life situations — anxiety, grief, burnout, forgiveness, loneliness, depression, and more.

## How it works

Each situation page (e.g. `/anxiety/`, `/grief/`, `/burnout/`) pairs 5 relevant Bible verses with a short prayer. The full list of situations is on the [home page](https://versefor.me/).

Available in English plus 9 translations (German, Spanish, French, Italian, Polish, Portuguese, Romanian, Tagalog, Ukrainian).

- Zero dependencies — static HTML, no server, no tracking
- Schema.org structured data
- Google Search Console verified

## Self-hosting

```bash
git clone https://github.com/verseforme/verseforme.git
cd verseforme
# open index.html directly or serve with:
npx serve .
```
